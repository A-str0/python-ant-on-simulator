# Тест-план для Sprint 2 — симулятор муравьиной колонии

## 1. Назначение документа

Документ предназначен для QA-инженера, который будет писать автотесты для второго спринта проекта «Муравьи».

План составлен по текущему состоянию проекта и отражает уже реализованные возможности системы.

---

## 2. Основание для тестирования

Основные источники проекта:

- `ants.py`
- `colony.py`
- `rooms.py`
- `storage.py`
- `main.py`
- `README.md`
- `pra_04_tests-1.pdf`

---

## 3. Текущее состояние проекта

На текущем этапе реализованы:

### Основные сущности

- базовый класс `Ant`;
- реестр видов муравьев;
- несколько видов муравьев;
- система статусов муравьев;
- система характеристик (`Б И Л Ь Я Р Д`);
- комнаты муравейника;
- назначение муравьев в комнаты;
- сохранение и загрузка колонии в JSON;
- случайные события;
- голосования;
- тренировка характеристик в комнатах;
- базовая CLI-логика.

### Реализованные комнаты

- склад пищи;
- кладбище;
- королевская комната;
- бильярдная;
- комната мягкого знака;
- феромоновый кружок.

### Реализованные механики

- старение;
- смерть;
- потребление еды;
- тренировка характеристик;
- смена комнаты;
- работа статусов;
- сериализация/десериализация;
- сохранение состояния колонии.

# 7. План тестов

---

## TC-001. Создание колонии

- Приоритет: P0
- Модуль: `colony.py`

### Проверить

1. Колония создается успешно.
2. Время равно 0.
3. Количество муравьев соответствует аргументу.
4. Еда сохраняется корректно.
5. Создаются комнаты по умолчанию.

### Ожидаемый результат

Колония создается без ошибок.

---

- Приоритет: P1

### Проверить

# 9. Основные риски

1. Частичная несогласованность требований и реализации.
2. Возможные ошибки сериализации сложных объектов.
3. Возможные ошибки при переносе муравьев между комнатами.
4. Ошибки при обработке статусов.
5. Скрытые баги при комбинации событий и комнат.
