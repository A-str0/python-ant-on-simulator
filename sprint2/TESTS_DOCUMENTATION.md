## Созданные тест-модули

### 1. test_voting.py (10 тестов)
**Тестирование механики голосования**

- `TestVotingResult` - тесты класса VotingResult
  - Инициализация с правильными значениями по умолчанию
  - Сериализация в dict (to_dict)
  - Десериализация из dict (from_dict)
  - Полный цикл сериализации/десериализации

- `TestColonyVoting` - тесты механики голосования в колонии
  - Голосование в пустой колонии возвращает пустой результат
  - hold_voting возвращает объект VotingResult
  - Голоса распределяются среди всех муравьев
  - Последнее голосование сохраняется в colony.last_voting
  - Распределение голосов имеет логичные пропорции
  - Переопределение королевой может произойти с определённой вероятностью

### 2. test_events.py (18 тестов)
**Тестирование системы случайных событий**

- `TestRandomEvent` - базовые тесты класса RandomEvent
  - Инициализация с правильными значениями
  - tick() уменьшает ticks_left
  - Сериализация/десериализация
  - Полный цикл (to_dict/from_dict)

- `TestColonyEvents` - тесты системы событий в колонии
  - Событие срок может истечь и быть удалено
  - Различные типы событий могут быть сгенерированы:
    - pheromone_death_spiral
    - smells_like_dead
    - fermented_syrup
    - billiard_addiction
  - Разрешение событий работает корректно
  - Функции-обработчики выполняют нужные действия

- `TestColonyEventSerialization` - сохранение событий
  - События сохраняются в colony.to_dict()
  - События восстанавливаются из colony.from_dict()

### 3. test_ant_features.py (50 тестов)
**Тестирование типов муравьев и системы характеристик**

- `TestAntTypes` - создание и типизация муравьев
  - Создание всех 4 типов (Harvester, WeaverAnt, RedReactiveAnt, ExplodingAnt)
  - Регистрация типов в реестре
  - Factory-функция create_ant работает для всех типов
  - Ошибка при создании неизвестного типа

- `TestAntStats` - система характеристик Б.И.Л.Ь.Я.Р.Д
  - Все 7 характеристик присутствуют
  - Начальные значения 5 для всех
  - Прогресс начинается с 0
  - Пользовательские распределения для WeaverAnt, RedReactiveAnt, ExplodingAnt

- `TestAntTrainStat` - обучение характеристикам
  - train_stat увеличивает прогресс
  - Уровень повышается при достижении 1.0 прогресса
  - Максимальное значение 10
  - Мёртвые муравьи не тренируются
  - Муравьи со статусом smells_like_dead не тренируются
  - billiard_main может тренировать только И
  - Накопление прогресса работает корректно

- `TestExplodingAntAbility` - способность взрыва
  - explode() убивает муравья
  - Урон ограничен 10
  - Урон зависит от Л характеристики

- `TestWeaverAntAbility` - способность строительства
  - build_leaf_room требует личинок
  - Возвращает правильный результат

- `TestAntSerialization` - сохранение муравьев
  - to_dict содержит полные данные
  - from_dict восстанавливает муравья
  - Factory функция ant_from_dict работает

### 4. test_rooms.py (37 тестов)
**Тестирование системы комнат**

- `TestRoom` - базовый функционал комнат
  - Инициализация с правильными значениями
  - is_full корректно определяет заполненность
  - assign_ant и remove_ant работают правильно
  - Сериализация/десериализация

- `TestDefaultRooms` - создание стандартных комнат
  - Возвращается словарь
  - Все требуемые комнаты созданы (9 типов)
  - Правильные параметры для каждой комнаты

- `TestRoomTrainMap` - карта обучения
  - Правильные характеристики для каждой комнаты:
    - food_storage: Б, Л
    - billiard_room: И
    - soft_sign_room: Ь

### 5. test_colony_integration.py (24 теста)
**Интеграционные тесты колонии**

- `TestColonyRoomAssignment` - назначение муравьев в комнаты
  - Назначение в валидную комнату
  - Ошибки для неверных индексов
  - Мёртвые муравьи не могут быть назначены
  - Муравей удаляется из предыдущей комнаты
  - Комната может быть переполнена

- `TestColonyTickMechanics` - механика тиков
  - Время колонии увеличивается
  - Муравьи стареют
  - Еда потребляется
  - Еда не может быть отрицательной
  - Муравьи умирают по достижении периода жизни
  - Счётчик живых муравьев точен

- `TestColonyBirth` - рождение новых муравьев
  - Рождение требует еды
  - Новые муравьи того же типа

- `TestColonyStatTraining` - обучение характеристикам
  - Муравей тренирует характеристики в комнате
  - Несколько характеристик тренируются одновременно
  - Разные комнаты тренируют разные характеристики

- `TestColonyDeath` - обработка смерти
  - Муравей правильно умирает по достижении жизненного периода

- `TestColonySerialization` - сохранение колонии
  - Полная сериализация/десериализация
  - Результаты голосования сохраняются

- `TestColonyStateTracking` - отслеживание состояния
  - Мораль королевы отслеживается
  - Уровень грибка отслеживается
  - Поддерживаются разные типы муравьев

- `TestColonyValidation` - валидация входных данных
  - Отрицательные значения отклоняются
  - Неправильные типы отклоняются
  - Булевы значения отклоняются как целые числа
